How it works

Copy the code, not a dependency.

Mozaik is not a package. Every component page has the full source with a copy button and the npm packages it needs. Paste the file into your project and it is yours to change.

  1. 1

    Pick a component

    Try it live in the gallery, check its props and the dependencies it lists.

  2. 2

    Copy the source

    One click copies the whole file. Paste it into components/ in any React project with Tailwind CSS v4.

  3. 3

    Make it yours

    No package to update, no wrapper to fight. Change the file however you like.

Quality gate

71 of 71 components pass every check.

The gate runs on every push. A component that fails still ships, marked beta, so you always know what you are getting.

Type-safe

Strict TypeScript across every component and demo.

Unit tested

Vitest and Testing Library on roles, labels and props.

Smoke tested

Playwright renders each demo and fails on runtime errors.

Reduced motion

Two screenshots 0.7s apart must match when motion is off.
