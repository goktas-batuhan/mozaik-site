About

Hi, I’m Batuhan. I build interfaces that feel considered.

Frontend developer. Mozaik is my open-source showcase: 48 animated React components, the source to copy, and this site that documents them. Everything here, from the tokens to the test pipeline, was designed and built as one system.

  • GitHub

What this project shows

Motion design in code
Springs, staggers, scroll and pointer-driven effects with Motion, CSS and raw WebGL.
Accessibility
Reduced-motion fallbacks tested in CI, keyboard support, live regions and real text for screen readers.
Design systems
One token layer for colour, radius and type, shared by every component and both themes.
Performance
Lazy previews, render loops that pause off screen, code highlighted at build time.
Testing and CI
Strict TypeScript, Vitest, Playwright smoke tests and a quality gate that labels each component.
Distribution
Copy-paste source: every page ships the full file, its dependencies and a copy button.

Under the hood

mozaik

Component source, tests, the quality gate and the registry build. React 19, TypeScript, Tailwind CSS v4, Motion, Vitest, Playwright, GitHub Actions.

mozaik-site

This website. It installs every component from the registry with the shadcn CLI, so the gallery doubles as an end-to-end test of the install path.
