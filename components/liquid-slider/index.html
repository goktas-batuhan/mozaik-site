Liquid Slider

A glass of water you fill by dragging its surface. The liquid sloshes and bubbles; under reduced motion it just rises.

Installation

1

Install the dependencies.

$npm install motion
2

Make sure you have the cn helper at lib/utils.ts.

$npm install clsx tailwind-merge
3

Copy the source into components/liquid-slider.tsx.
