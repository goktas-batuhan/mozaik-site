Price Ticker

A price that rolls its digits on every update, flashes green or red, and shows a percent change badge.

Installation

1

Run the shadcn CLI in a project that has Tailwind CSS v4.

$npx shadcn@latest add https://raw.githubusercontent.com/goktas-batuhan/mozaik/main/public/r/price-ticker.json
2

Prefer short names? Add the registry once to components.json.

components.json
{
  "registries": {
    "@mozaik": "https://raw.githubusercontent.com/goktas-batuhan/mozaik/main/public/r/{name}.json"
  }
}
$npx shadcn@latest add @mozaik/price-ticker
